# 마이링크 (MyLink)

이 프로젝트는 shadcn/ui가 포함된 Next.js 템플릿으로 구축된 개인용 링크 공유 서비스입니다.

## 컴포넌트 추가하기

앱에 새로운 컴포넌트를 추가하려면 다음 명령어를 실행하세요:

```bash
npx shadcn@latest add button
```

이 명령어를 실행하면 `components/ui` 디렉토리에 UI 컴포넌트가 생성됩니다.

## 컴포넌트 사용하기

앱에서 컴포넌트를 사용하려면 다음과 같이 임포트하세요:

```tsx
import { Button } from "@/components/ui/button";
```
